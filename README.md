## 🎓 واجهة الأستاذ

### المسار الكامل:
1. **تسجيل الدخول** ← اسم المستخدم + كلمة المرور
2. **المعلومات الشخصية** ← الرتبة، الشهادة، التخصص، الخبرة
3. **السداسي الأول** ← حتى 5 رغبات (2 إجبارية) + حفظ مؤقت + تأكيد
4. **السداسي الثاني** ← يُفتح بعد تأكيد الأول + تأكيد نهائي يُقفل السداسيين معاً
5. **بطاقة الرغبات** ← عرض + PDF + طباعة

## 🛡 لوحة الإدارة

### الخطوات المنهجية (بالترتيب):
```
① إدخال الأساتذة وحساباتهم
② ضبط المجموعات والأفواج (sections × groups)
③ إدخال المقاييس في كل سداسي
④ انتظار تسجيل الأساتذة رغباتهم
⑤ ★ استعراض الرغبات الخام وتحليلها  ← جديد
⑥ تشغيل خوارزمية الإسناد
```

### ★ صفحة استعراض الرغبات الخام (AdminWishesViewerPage):
خمس طرق عرض مستقلة عن الخوارزمية:

| الطريقة | الوصف |
|---------|-------|
| **حسب الأستاذ** | كل أستاذ مع رغباته المرتبة حسب السداسي والترتيب |
| **حسب المقياس** | كل مقياس مع كل من طلبه مرتبين حسب رقم الرغبة |
| **جدول كامل** | كل الرغبات في جدول واحد مع كل التفاصيل |
| **التصادمات المحتملة** | الأزواج التي ستحتاج الخوارزمية للبت فيها |
| **إحصاءات** | أكثر المقاييس طلباً + توزيع الرغبات + حالة الأساتذة |

**تصدير Excel (3 صيغ):**
- القائمة الكاملة (كل رغبة في سطر)
- حسب الأستاذ (كل أستاذ في سطر مع رغباته الـ5)
- حسب المقياس (كل مقياس في سطر مع الطالبين له)
- التصادمات (ملف مستقل للتصادمات المحتملة)

## 🔢 منطق الإسناد

```
لكل رغبة بالترتيب (wish_order: 1 → 5):
  ① إذا الحجم الساعي > 9س → تجاهل
  ② إذا وجدت slot فارغة → إسناد فوري (بغض النظر عن قوة الأستاذ)
  ③ إذا تصادم (نفس slot، نفس رقم الرغبة) → المعايير تحسم
     - تطابق التخصص: 40%
     - الرتبة العلمية: 30%
     - التدريس السابق: 20%
     - الخبرة: 10%

الحجم الساعي:
  محاضرة = 2.25س/أسبوع لكل section
  أعمال موجهة = 1.5س/أسبوع لكل group
  الحد الأقصى = 9س/أسبوع
```

## 📊 قاعدة البيانات الرئيسية

| الجدول | الوصف |
|--------|-------|
| `professors` | الأساتذة + حقول القفل |
| `levels` | 14 مستوى |
| `level_semesters` | المجموعات والأفواج لكل مستوى×سداسي |
| `modules` | المقاييس (semester=1 أو 2) |
| `wishes` | الرغبات (semester مستقل) |
| `assignments` | الإسنادات (section_number, group_number, wish_order_satisfied) |
| `assignment_criteria` | معايير الإسناد قابلة للتعديل |
| `academic_settings` | إعدادات الموسم |
| `admins` | المشرفون |
